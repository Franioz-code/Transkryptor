# Screenshots

The main `README.md` references the four images below. To capture a clean window
shot on macOS: press **⌘⇧4**, then **Space**, then click the Transkryptor window
(this grabs just the window, with a drop shadow). Save each one here with the exact
name listed, then `git add docs/screenshots && git commit && git push`.

| File | What to capture |
|---|---|
| `01-record-cockpit.png` | Main window: the 1‑2‑3 recording panel (source picker, lecture name, Start). |
| `02-notes.png` | A generated lecture open — show the structured notes (objectives / key takeaways / glossary / self-test). |
| `03-diagram-formula.png` | A note section with a rendered Mermaid diagram and/or a LaTeX/chemistry formula. |
| `04-notch-gallery.png` | The notch cockpit and/or the screenshot gallery (timestamped shots, crop). |

Tip: pick lectures with clean names for the sidebar (you can rename/delete the
`TEST*` entries first) so the shots look polished for a CV.
